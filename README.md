# trade

Claude Code skill **`cash-app-trader`** (`.claude/skills/cash-app-trader/`) for running a small
(e.g. $10) Cash App Investing budget: it scans for trade ideas, calculates risk and position size,
builds an animated chart dashboard, and preps order tickets that **you** place in Cash App.
Cash App has no public trading API, so Claude never holds money or places orders. Not financial advice.

Ask Claude things like "find me trades for my $10", "how risky is NVDA?", or "show my dashboard".
